# Armored SMP SS2

This plugin will provide a new game mechanic that player need to be survive
with a single of armor pieces

## Gameplay

A player will spawn into the world with full armor toughness goals to survive and gain an Armored Medal

## Features

- Health Boost (Temporary) when player not wearing any armor
- Armor Toughness (Temporary) when a player has slept consistently for 3 nights or more

## New Items

- Heart Cake: (Vanishing Curse, Unstorable) This will give a permanent +1 max health when eaten at full moon
- A Missing soul: This will randomly drop when player has died
- Nether Armored Beacon: This is a beacon that use for access into Nether world
- The End Armored Beacon: This is a beacon that use for access into End world
- Bronze Core: This is a core that use for crafting Armored Spirit 
- Golden Core: This is a core that use for crafting Armored Spirit
- Diamond Core: This is a core that use for crafting Armored Spirit
- Netherite Core: This is a core that use for crafting Armored Spirit
- Unstable Core: This is a core that use for crafting Armored Spirit
- Armored Spirit: (Vanishing Curse, Unstorable, 10 Amount) This is a charm that will give a player a toughness working like a **totem of undying**
